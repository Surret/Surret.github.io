The Steam Lamp Project

A personal project in creative problem-solving and 3D printing.

This project was built to create headlights and rear lights for a miniature steam engine. The scale of the engine is a 1/3 recreation of a real steam engine. The design was to create something that would look like it belonged on the train as both a functional component and an aesthetic one.

The main challenge was designing a housing that was both visually compelling and fully functional, ensuring a perfect fit for the torch's internal components. I focused on a steam-punk aesthetic, drawing inspiration from old-world technology and machinery to create a design that was both practical and true to the engine's style.

Key Challenges & Solutions

  • Hiding Layer Lines: Standard 3D printing creates visible layer lines. I solved this by using a "fuzzy skin" setting in the slicer software. This created a randomized, textured surface that effectively disguised the layers and made it look less like a 3D print.
  • Dealing with Overhangs: With the lamp being hollow and having significant overhangs, using automatic tree supports proved ineffective. The tree supports would get stuck inside the top of the hollow lamp and the overhangs on the bottom would not print correctly, causing the print to fail. The solution was to design and add my own custom supports and add a slope on the inside of the lamp's top to eliminate the need for any internal supports, resulting in a cleaner print.
  • Component Integration: The lamp itself only houses the LEDs and the lens from the torch. All the electronics are being wired separately to the torch's main body, enabling the lights to be turned on and off from the driver's seat of the steam engine, which is a considerable distance with the trailer included. This required precise measurements to ensure the lens fit perfectly and that the wiring could be channeled correctly. For the rear lights, a special red colour container was designed and printed to change the light's normal white colour.

Personal Learning

  • The Value of Slopes: This project taught me a valuable lesson in 3D printing: using slopes in a design can dramatically improve print quality. By adding a simple slope to the inside of the lamp, I was able to avoid the need for internal supports entirely, which made the final print much cleaner and easier to post-process. This is a design principle I'll definitely carry forward.
  • Creative Component Use: I learned that when working with non-changing LEDs, I could use a simple, printed container to change the light's colour. This simple solution saved a lot of time and money, eliminating the need to purchase multiple coloured LEDs for different purposes.

Tools & Technologies

  • 3D Modelling: Fusion 360
  • 3D Printer: Creality Ender 3 V2
  • Slicing Software: Cura
  • Materials: PLA Filament (Black)

Future Possibilities

  • Standalone Design: To transition this from a personal project to a product with commercial viability, a key next step would be to miniaturise the electronics and integrate them directly into the lamp housing. This would eliminate the trailing wires and make the lamp a self-contained unit, perfect for a wider audience.
